# Setup

## Prerequisites

R 4.0 or later with packages: tidyverse, data.table, survey, geepack, boot, ggplot2, gridExtra, knitr, kableExtra.

## Configuration

Edit scripts/setup/00_setup_project.R to specify local paths.

## Execution

Execute scripts in numerical order by phase: 00 → 01 → 10–14 → 20–24 → 30–35 → 40–53.

Package versions are documented in logs/sessionInfo.txt.
