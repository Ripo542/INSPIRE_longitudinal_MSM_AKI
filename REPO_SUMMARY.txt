================================================================================
Longitudinal intraoperative hypotension and postoperative acute kidney injury
================================================================================

Repository:
https://github.com/Ripo542/INSPIRE_longitudinal_MSM_AKI

Contents:
R code for longitudinal restructuring, inverse probability weighting, and weighted outcome modeling in the INSPIRE perioperative dataset. Includes analytical scripts, documentation, and R session information.

================================================================================
STRUCTURE
================================================================================

scripts/          R analysis scripts organized by analytical phase (00–53)
docs/             Documentation
logs/             R session information

================================================================================
EXECUTION
================================================================================

Scripts are organized into sequential analytical phases:
00 → 01 → 10–14 → 20–24 → 30–35 → 40–53

================================================================================
REQUIREMENTS
================================================================================

R 4.0 or later.
Required packages are documented in logs/sessionInfo.txt.

The INSPIRE dataset is required for reproducibility and is available separately through PhysioNet under the corresponding data use agreement.

================================================================================
CONFIGURATION
================================================================================

Edit scripts/setup/00_setup_project.R to specify local paths.
