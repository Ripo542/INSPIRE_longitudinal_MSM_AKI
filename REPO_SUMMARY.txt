================================================================================
Longitudinal intraoperative hemodynamics and acute kidney injury
================================================================================

Repository: https://github.com/Ripo542/INSPIRE_longitudinal_MSM_AKI

Contents: R analytical code for marginal structural modeling of intraoperative 
hemodynamic exposures and postoperative acute kidney injury. Includes analytical 
scripts, documentation and R session information.

================================================================================
STRUCTURE
================================================================================

scripts/          49 R analysis scripts organized by phase (00–53)
docs/             Documentation
logs/             R session information

================================================================================
EXECUTION

Scripts are organized sequentially: 00 → 01 → 10–14 → 20–24 → 30–35 → 40–53

================================================================================
REQUIREMENTS

R 4.0+, packages documented in logs/sessionInfo.txt
INSPIRE dataset (for reproducibility) Available on PhysioNet 

================================================================================
CONFIGURATION

Edit scripts/setup/00_setup_project.R for local paths.
